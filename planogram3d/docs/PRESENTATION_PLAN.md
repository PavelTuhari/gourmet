# План презентации модуля planogram3d

**Аудитория:** руководство розничной сети, ИТ-директор, руководители
розницы и e-commerce.
**Длительность:** 16–21 минута (16 слайдов) + вопросы.
**Файл:** `docs/presentation.pptx` (все скриншоты — реальные, сняты с
работающей системы).

## Тезисы по слайдам

1. **Титул.** Одна платформа связывает мерчандайзинг, операции магазина,
   обучение персонала и последнюю милю.
2. **Возможности.** Показать широту: каждый блок — работающий раздел
   системы, не концепт.
3. **Архитектура.** Ядро `planogram3d.core` — чистый Python (только
   plotly), встраивается в любую систему; веб-режим — Flask; Roblox —
   отдельный пакет. Все данные заводятся через один объект `Store`.
4. **3D-планограмма.** Подчеркнуть: глубина стопки товара = остаток,
   red = out-of-stock; переключение режимов кнопками; карточки товара
   при наведении.
5. **Соответствие.** Проверки автоматические: тяжёлый товар наверху,
   доля полки по контракту, уровень глаз, расхождение факт/план,
   OOS-алерты. Расширяется своими правилами (`extra_checks`).
6. **Карта сети.** Карта полностью автономна (выгрузка OSM в пакете);
   Zabbix — реальный API или эмуляция.
7. **РЦ.** Опциональный (`PLANOGRAM_DC=0`); показать сквозную цепочку:
   пустая полка → заказ → рейс → пополнение.
8. **Зал.** Единый поток событий: эмулятор и реальные кассы/CCTV
   отправляют одинаковый JSON (`/api/instore/<id>/ingest`).
9. **Вход в магазин.** Wow-момент демо: подлёт камеры, «дверь»,
   интерьер. Держать наготове живую систему.
10. **Тренажёр.** Обучение = игра: цели смены, звёзды, советы. Товары
    и цены — из реальной планограммы магазина.
11. **Roblox.** Мотивация команды: баллы и бейджи за пройденные кейсы;
    конвертер генерирует готовый place с Luau-тренажёром.
12. **Доставка.** План/факт на Ганте — инструмент диспетчера; GPS из
    курьерского приложения, эмуляция как fallback.
13. **ИИ-табло прибытия.** Каждый пункт доставки (магазин, адрес
    покупателя) видит на карте онлайн-табло машин поставщиков и
    курьеров; время просчитывает онлайн-обучаемая ИИ-модель
    (EWMA-скорости, трафик по часам, ±1σ). Аналогия для аудитории:
    «умные остановки» городского транспорта (Urban Way, Бельцы).
14. **Топливный контур.** Тот же архитектурный приём, что и у розничной
    доставки: автономная карта, движение по реальным дорогам, ИИ-табло
    прибытия на общем прогнозисте (`eta_ai.py`). Отличие — вместо
    эмулированного GPS здесь можно подключить настоящую систему
    учёта ERP Artgranit (`ARTGRANIT_URL`); при её недоступности контур
    сам и без ошибок возвращается к эмуляции. Показать сквозную цепочку:
    остаток на станции падает ниже порога → автоматический рейс
    бензовоза → табло на карте.
15. **Чек.** Два форм-фактора курьера; чек в момент вручения, печатная
    форма 80 мм.
16. **Итоги.** Цифры: 6 магазинов сети в эмуляции, 46 АЗС в топливном
    контуре, 4 группы проверок, 3 смены тренажёра, 2 сцены Roblox,
    1 объект `Store` для всех данных. Предложение: пилот на одном
    реальном магазине.

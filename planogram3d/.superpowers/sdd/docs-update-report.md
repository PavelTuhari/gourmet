## Сквозная проверка (Задача 6 плана `PLAN_FUEL_AUTOORDER.md`)

Окружение: Artgranit поднят на `http://127.0.0.1:3003` (ответ `/` —
302, редирект на форму логина), planogram3d — на `:8050` с уже
выставленной `ARTGRANIT_URL`.

**Шаг 1 — `GET /api/fuel/state`:**
```
source: artgranit
stations: 46
trips: 3
depot: {'id': 1, 'name': 'Нефтебаза Сынжера', 'lat': 46.9503,
        'lon': 28.8189, 'capacity_l': 400000.0, 'current_l': 248000.0,
        'fill_pct': 62.0}
```
Подтверждено: источник — `artgranit` (не эмуляция), станций 46, рейсы
реальные (не заглушка). Это главное обещание контура выполняется.

**Шаг 2 — инициация нового прогона автозаказа `POST
/api/plg/fuel/autoorder`:**
```
$ curl -s -X POST http://127.0.0.1:3003/api/plg/fuel/autoorder -w "HTTP %{http_code}\n"
HTTP 403
{"demo": true, "error": "Демо-режим: изменение данных доступно после
входа в систему", "success": false}
```
`GET /` Artgranit отдаёт форму логина («Вход — Artgranit OCI») —
запись в систему требует аутентификации оператора. Это ожидаемо и
осознанно совпадает с архитектурой контура (см.
`docs/PLAN_FUEL_AUTOORDER.md`, «Глобальные ограничения»: *«Artgranit
только читается. Никаких записей в его API из planogram3d... инициацию
автозаказа выполняет оператор в Artgranit»*) — planogram3d специально
спроектирован как read-only клиент ERP, никогда не пишет в неё.

**Честный вывод:** прочитать состояние (46 станций, живые рейсы,
`source=artgranit`) удалось и это подтверждённая, не эмулированная
интеграция. Инициировать новый прогон автозаказа через API **не
удалось**, потому что запись в Artgranit требует входа оператора в его
собственный интерфейс (логин/пароль), которых у меня нет и вводить
я не вправе (учётные данные — из списка запрещённых к вводу действий).
Это не дефект контура и не повод сомневаться в интеграции: по плану
инициация автозаказа — сознательно операторское действие в самой ERP,
planogram3d лишь отображает результат опросом. Живых 3 рейса в текущем
состоянии — уже результат ранее выполненной (в прошлой сессии, задача 3
плана) инициации в Artgranit; я это не выдаю за собственноручно
подтверждённый end-to-end прогон нового автозаказа, только за
подтверждённое чтение живых данных из ERP.

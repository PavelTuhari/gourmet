3D-инновация для ERP — самодельным модулем

ERP знает всё, но показывает таблицами. Половина данных ритейла пространственна — полка, зал, город, маршрут.
  • 3D переносит интерпретацию с человека на систему: пустая полка краснеет, грузовик едет по карте, очередь видна как очередь
  • Пять контуров ERP одним модулем: мерчандайзинг, запасы/РЦ, IoT-мониторинг, доставка, обучение персонала — на одних данных
  • Самодельный — это стратегия: ядро ~850 строк Python, одна зависимость, без лицензий и чужих облаков
  • Интеграция с любой ERP (1С, SAP, Odoo, самописной) через один объект Store: адаптер CSV/REST в десятки строк
  • Эмуляторы всех внешних контуров: демо работает в первый день, интеграции подключаются по готовности
  • Дорожка: PoC на своих данных за 2 недели → пилотный магазин за месяц → сеть за квартал

3D-планограмма: продажи и утверждённая выкладка

  • Два режима одной сцены — «Текущее состояние продаж» и «Утверждённая планограмма», переключение кнопками
  • Теплокарта остатков: зелёный — полная полка, красный полупрозрачный — out-of-stock
  • Глубина стопки товара пропорциональна остатку
  • Утверждённая выкладка раскрашена по поставщикам — видны доли полки по контрактам
  • Карточка при наведении: SKU, поставщик, фейсинги, остаток, скорость продаж, запас в днях
  • Отчёт — автономный HTML-файл: можно отправить письмом

Контроль соответствия: регламент и контракты

Живая карта сети, Zabbix и логистический центр

  • Карта из OpenStreetMap: улицы, здания, Волга — автономна, интернет не нужен; 2D/3D с выдавливанием по этажности
  • Эмуляция торгового дня (1 с = 10 мин): продажи, выручка, пустые полки, лента событий
  • Zabbix: бейдж активных проблем на каждом магазине, список в карточке (реальный API или эмуляция)
  • РЦ-буфер: пустая полка → заказ → грузовик по карте → пополнение; перезаказ у поставщиков
  • Игровой вход в магазин: подлёт камеры, «дверь», интерьер с тремя вкладками

Симуляция зала: датчики магазина на одной схеме

  • Покупатели ходят к реальным стеллажам планограммы, весам, кассам и СКО
  • Очереди у касс в реальном времени; оценка трафика: датчики входа/выхода − очереди = равномерно по залу
  • ТСД: BLE-маяки (±0.5–1 м) в торговой зоне, LoRa (±2–3.5 м) на остальной площади, круги точности
  • Холодильники: температура, дверца, компрессор, тревоги; зоны скоропорта выделены
  • Расходники: лента касс/весов, кульки — заявки на замену
  • Единая шина событий: эмулятор или реальные кассы/CCTV (POST /api/instore/<id>/ingest)

Тренажёр персонала и мотивация в Roblox

  • Игра в жанре тайм-менеджмента: склад → полки → касса, уборка, лента, холодильники
  • Покупатели с терпением ❤ — уходят злыми, если ждать
  • 3 смены-уровня, звёзды, разбор ошибок и советы в конце
  • Регистрация: имя + ник Roblox; баллы и бейджи за кейсы
  • Open Cloud: DataStore + MessagingService — поощрение видно прямо в Roblox-опыте
  • Конвертер robloxkit: зал с реальной планограммой → .rbxlx для Roblox Studio

Интернет-заказы: сборка → маршруты → Гант → GPS → чек

  • Заказы привязываются к ближайшему магазину, сборка по планограмме
  • Группировка в маршруты по 2–4 адреса («ближайший сосед»)
  • Диаграмма Ганта: план/факт каждого плеча, линия «сейчас», опоздания красным
  • Курьеры на карте по GPS из приложения (POST /api/delivery/gps); без телеметрии — эмуляция
  • Чек в момент вручения: Android с облачной кассой или терминал SmartOne с ФН на борту; печатная форма 80 мм

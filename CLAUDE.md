# Рабочие правила для Claude в этом репозитории

1. **Всё делаю сам — пользователю заданий не даю.** Никаких «выполните
   команды», «клонируйте», «установите» в ответах. Если что-то нужно
   запустить, настроить, проверить — запускаю, настраиваю и проверяю
   сам, прямо здесь, в своей среде.
2. **Запустил — покажи.** Каждая функциональность подтверждается
   реальным запуском и скриншотами работающей системы, а не описанием.
3. Если моя среда физически не позволяет что-то сделать (нет доступа к
   машине пользователя, нет macOS/дисплея) — сначала выжимаю максимум
   из своей среды (виртуальный дисплей, эмуляторы, альтернативные
   пути), и только потом коротко и честно называю границу, не
   перекладывая работу на пользователя.
4. Все результаты — коммитом в ветку задачи с пушем; артефакты
   (отчёты, скриншоты, файлы) отправляю пользователю в чат.

## Контекст проекта

Разработка ведётся в `planogram3d/` — самодельный 3D-модуль для ERP
(планограммы, цифровой двойник сети, тренажёр персонала, доставка).
Рабочая ветка: `claude/3d-sales-visualization-fsbyam`.
Запуск системы: `python3 -m planogram3d.webapp` (веб) или
`python3 -m planogram3d.desktop` (нативное окно, pywebview).
